# Task-Ai-
A short presentation project about the advantages and disadvantages of AI-powered reminders
## Topic
Artificial intelligence is increasingly used in everyday life. One example is smart reminders that can analyze user habits and suggest actions automatically.

## What the presentation includes
- What AI reminders are
- Their main advantages
- Their disadvantages
- A final conclusion about balanced use

## Main advantages
- Personalization
- Time saving
- Smart suggestions

## Main disadvantages
- Dependency on technology
- Privacy concerns
- Possible mistakes

## Conclusion
AI reminders can make life easier and more convenient, but they should be used carefully and with balance.
